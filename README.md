
# API-v1: Atividade de Sistemas Corporativos

## 💻 Sobre o Projeto
Este projeto consiste na criação de uma API RESTful utilizando o framework Django e o Django REST Framework. O objetivo principal é servir como atividade prática para a disciplina de Sistemas Corporativos, demonstrando a integração com um banco de dados SQL Server (MSSQL).

## 🚀 Tecnologias Utilizadas
*   **Python:** Linguagem de programação principal.
*   **Django:** Framework web para desenvolvimento da API.
*   **Django REST Framework:** Conjunto de ferramentas para a construção de APIs web.
*   **mssql-django:** Adaptador para conectar o Django a um banco de dados SQL Server.
*   **SQL Server (MSSQL):** Banco de dados utilizado para o armazenamento dos dados.
